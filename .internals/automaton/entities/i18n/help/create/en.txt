CREATE COMMAND

This command creates a given [JOB] directory set inside
$AUTOMATON_DIRECTORY_JOBS directory.

It creates both 'start.sh' and 'start.ps1' placeholder files.

The default CI directory (when $AUTOMATON_DIRECTORY_JOBS is not explicitly
specified) is './.internals/ci/' relative to the current directory.
The pathing pattern is as follows:
	* path:    ${AUTOMATON_DIRECTORY_JOBS}/[JOB]/start.{sh,ps1}
	* default:             ./.internals/ci/[JOB]/start.{sh,ps1}
	* custom:            /path/to/your/dir/[JOB]/start.{sh,ps1}
